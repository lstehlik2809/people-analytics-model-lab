How the models learn

For small and medium-sized people analytics datasets, a tabular foundation model can offer a first predictive comparison with less manual data preparation and tuning. In this lab, you choose the outcome and predictors. The app prepares the inputs and uses Kumo’s pretrained weights directly.

Newer models can handle much larger tables. Prior Labs reports running TabPFN-3 on one million rows on an H100 GPU. This browser lab uses 1,470 fictional employee records to show the workflow on a small dataset.

Tabular foundation models

These models are pretrained across many prediction tasks on tables. Models such as Kumo Tabular and TabPFN can take rows with known outcomes as examples and predict an outcome for new rows with the same columns. This is called in-context learning.

This lab uses Kumo Tabular Small, the smallest of NVIDIA’s three Kumo Tabular sizes at about 28 million parameters. It was pretrained on simulated tables.

Large language models

Kumo and text-based large language models (LLMs) such as GPT-3 use transformers and can use examples with their weights fixed. GPT-3 is pretrained to predict the next token, or piece of text, and takes examples in a prompt. Kumo takes labeled rows as context and returns class probabilities or a numeric prediction for each new row.

Linear models and Random Forest

Linear regression fits coefficients to predict a number. Logistic regression fits coefficients to estimate class probabilities. Random Forest grows trees on resamples of the training rows and combines their predictions.

The lab lightly regularizes both regression models, uses one-vs-rest logistic regression for multiple classes, and fits a 200-tree Random Forest. In regression, each tree can split on any selected predictor.

How this lab compares them

About 80% of the 1,470 fictional IBM employee rows are used as training examples. Kumo reads these rows as context with its pretrained weights fixed. Linear or logistic regression and Random Forest fit to the same training set. All three are scored on the remaining rows, whose outcomes are held back during prediction. The classification split keeps each class represented in both sets.

For classification, the No model column shows what each score would be without one. One split leaves room for chance, since the test set has about 294 rows. After a run, you can repeat the comparison on nine more splits of the same rows to see the mean and range of each score.
