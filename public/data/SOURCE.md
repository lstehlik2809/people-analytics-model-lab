# IBM HR Analytics Employee Attrition & Performance

The dataset contains records for 1,470 fictional employees created by IBM data scientists. The Attrition flag has no documented observation window.

- Original dataset uploaded by pavansubhasht. [Kaggle dataset](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
- Kaggle dataset version 1, last updated 31 March 2017. Original archive member `WA_Fn-UseC_-HR-Employee-Attrition.csv`.
- The app bundles the same unaltered CSV used by Bayes in Your Browser. [Source record and retrieval details](https://github.com/lstehlik2809/bayes-in-your-browser/blob/main/data/SOURCE.md)
- SHA‑256 `a5c31e38bd7fafc9bc333884eb181b06b41b8e5e488e8f7ccb27199fb3be7659`
- 35 columns, 1,470 distinct EmployeeNumber values, 237 Attrition=Yes records and no missing cells.
